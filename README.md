# HENLA: Human-Centric Experiential Neural Learning Architecture

## Status
**HENLA is a neuro-symbolic cognitive architecture currently entering the HENLA-EXT External Validation Program.**

It has successfully passed **Internal Validation (HENLA-7 Final)** with validated in-domain learning and OOD analogical arbitration.

The purpose of this repository is to make the architecture reproducible, inspectable, falsifiable, and available for independent review.

---

## Overview
HENLA is built around a symbolic-experiential core, focusing on:
- **Episodic Memory**: Structured recording of environmental and knowledge experiences.
- **Evidence-Based Hypergraph**: A learning mechanism that promotes relations based on accumulated evidence and prediction error.
- **Viability Signals**: Internal status signals (e.g., energy, stability) that guide deliberation.
- **Deliberative Scratchpad**: A dedicated reasoning space for planning and meta-reasoning.
- **Hierarchical Subgraphs**: Organized domain-specific knowledge civilizations.
