# HENLA Claim Boundary

This document defines the strictly enforced boundaries for claims regarding the HENLA architecture.

## 1. Allowed Claims (Validated Internally)
- **Symbolic-Experiential Foundation**: The architecture is built on episodic memory and evidence-based hypergraphs.
- **Architectural Completeness**: The platform implements episodic storage, viability signaling, prediction error detection, deliberative scratchpads, and specialized domain subgraphs.
- **Area-Specific Neuralized Subgraphs**: Each cognitive area (Episodic, Procedural, Semantic, etc.) integrates symbolic memory with a local neural module interface.
- **Inter-Area Messaging**: Areas communicate via structured cognitive messages (novelty, risk, analogy candidates).
- **Neuro-Symbolic Arbitration**: A dedicated layer integrates neural suggestions with symbolic safety and ethics constraints.
- **Internal Consistency**: The system successfully passes internal benchmarks for both symbolic and neural civilization suites.

## 2. Forbidden Claims (Strictly Prohibited)
- **AGI (Artificial General Intelligence)**: HENLA is a specialized cognitive architecture, not a general human-level mind.
- **Consciousness / Sentience**: HENLA processes data logs of experience; it does not possess subjective awareness.
- **Brain-Like Mind**: While inspired by neurobiology, HENLA is an engineering construct, not a biological simulation.
- **Omniscience**: Claims that HENLA "possesses all human knowledge" are false.

## 3. Pending Claims (Requires External Validation)
- **Neural Generalization**: Proof that learned weights outperform symbolic baselines on unseen, high-complexity tasks.
- **Learned Utility**: Quantifiable performance gain from the neural federation in real-world environments.
- **Robust Generalization**: Performance on repositories not authored by the developers.
